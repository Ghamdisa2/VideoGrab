# VideoGrab — محمّل فيديو وصوت (MP3)

يعتمد على yt-dlp + FFmpeg: يدعم تيك توك، انستقرام، يوتيوب، اكس، فيسبوك، تيليجرام، سناب وآلاف المواقع. مجاني وبدون إعلانات.

## الطريقة الأسهل للحصول على التطبيقين (بدون برامج على جهازك)
1. أنشئ مستودعًا على github.com وارفع محتوى هذا المجلد.
2. ادخل تبويب Actions ثم Build VideoGrab ثم Run workflow.
3. بعد دقائق نزّل من Artifacts:
   - VideoGrab-Android-APK: ملف APK ثبّته على جوالك (فعّل "التثبيت من مصادر غير معروفة").
   - VideoGrab-windows-latest: ملف VideoGrab.exe للكمبيوتر (وهناك نسخ macOS وLinux).

## تشغيل نسخة الكمبيوتر مباشرة
    cd desktop
    pip install -r requirements.txt
    python app.py          # للتشغيل
    python build.py        # لإنشاء ملف exe في dist/

## الميزات
- تحميل قوائم التشغيل كاملة (خيار "تحميل قائمة التشغيل كاملة")، وتُحفظ في مجلد باسم القائمة مع ترقيم الملفات. لو فشل عنصر يكمل الباقي.
- واجهة عربية وإنجليزية بزر تبديل (English / العربية) في النسختين.

## الاستخدام
- الكمبيوتر: الصق الروابط (رابط في كل سطر) ← اختر فيديو أو MP3 والجودة ← تحميل.
- قوائم التشغيل: الصق رابط القائمة وفعّل الخيار. على الأندرويد تُنسخ الملفات بعد انتهاء القائمة كلها، فاحرص على توفر مساحة كافية.
- الأندرويد: الصق الرابط أو اضغط "مشاركة" من تيك توك/انستقرام وغيرها واختر VideoGrab. الملفات تُحفظ في Download/VideoGrab.
- للحسابات الخاصة أو المحتوى المقيّد: في نسخة الكمبيوتر اختر "كوكيز من" متصفحك.

## ملاحظات
- النسخة المحمولة تحدّث yt-dlp تلقائيًا؛ على الكمبيوتر أعد البناء بعد `pip install -U yt-dlp` إذا توقف موقع عن العمل.
- حمّل فقط ما لك حق تحميله أو يسمح به صاحبه؛ بعض المنصات تمنع التحميل في شروطها.
